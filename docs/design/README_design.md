# Design

## Design Process

The SafeSchool interface was developed through an iterative two-phase process.

### Phase 1 — Initial mockups (March 2026)

The mockups in [`mockups/v1-initial/`](./mockups/v1-initial/) were produced at the start of the project to frame the screen structure and main user flows. They helped identify the key views (report submission, profile, quiz) and informed the component breakdown before development began.

### Phase 2 — Final UI

As the application took shape, the interface evolved toward a design system built on **shadcn/ui** and **Tailwind CSS v4**. The visual rules are documented in [`graphic-charter.md`](./graphic-charter.md) and [`colors.md`](./colors.md).

## Technologies utilisées

### Frontend
- **React** — librairie pour construire l'interface
- **TypeScript** — JavaScript avec typage
- **Vite** — outil qui compile et sert le frontend
- **Axios** — pour envoyer les requêtes HTTP vers le backend
- **React Router** — pour naviguer entre les pages

### Backend
- **NestJS** — framework Node.js pour construire l'API
- **TypeScript** — même langage que le frontend
- **TypeORM** — pour communiquer avec la base de données
- **JWT (JSON Web Token)** — pour l'authentification
- **Passport** — middleware pour gérer les stratégies d'auth
- **Bcrypt** — pour chiffrer les mots de passe

### Base de données
- **PostgreSQL** — base de données relationnelle
- **pgAdmin** — interface graphique pour gérer la base

### Infrastructure
- **Docker** — pour containeriser les services
- **Docker Compose** — pour orchestrer les 3 conteneurs (frontend, backend, database)

### Outils de développement
- **Git / GitHub** — pour versionner et partager le code
- **curl** — pour tester les APIs depuis le terminal

### Communication
- **GitHub** — gestion de projet
- **Slack** — organisation, collaboration, information

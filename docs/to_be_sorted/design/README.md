# Design

## Processus de design

Le design de SafeSchool a suivi une démarche itérative en deux phases :

### Phase 1 — Maquettes initiales (mars 2026)

Les maquettes dans [`mockups/v1-initial/`](./mockups/v1-initial/) ont été réalisées en début de projet pour cadrer la structure des écrans et les flux utilisateurs principaux. Elles ont permis d'identifier les vues clés (signalement, profil, quiz) et de structurer le découpage des composants avant le développement.

### Phase 2 — UI finale

Suite à l'implémentation, l'interface a évolué vers un design system basé sur **shadcn/ui** et **Tailwind CSS v4**, avec une charte graphique définie dans [`graphic-charter.md`](./graphic-charter.md) et [`colors.md`](./colors.md).

Les screenshots de l'application finale sont disponibles dans [`screenshots/`](./screenshots/).
